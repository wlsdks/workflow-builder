## 정규화 사전 운영 규칙

1. 본문에서 동의어가 감지되면 줄 끝에 배지 표시(예: `액셀에 정리` → `Excel?`) → **클릭 1회로 확정.** 입력이 아니라 **확인**
2. 매칭 실패 시 자유 텍스트로 저장하되 **주 1회 미매칭 상위 20건을 카탈로그 확장 큐**에 올린다. **이 큐가 "도구명 정규화 사전"이라는 데이터 자산을 실제로 축적하는 유일한 경로다**
3. **연결성 '하' 도구가 붙은 단계를 자동화 후보에서 배제하지 않는다** — 오히려 *"도구를 바꾸면 상이 됨"*(엑셀→구글시트, 종이→전자계약, 홈택스→바로빌) 형태의 **선행 개선 제안**으로 분리 출력한다

# B. 예외 프롬프트 뱅크

> 원칙: **존재가 아니라 빈도로 묻는다.** "예외 있나요?"는 무조건 "없어요"가 나온다.
> 트리거: 단계 저장 직후 **1개만**, 인라인 각주 입력란으로. **절대 모달로 띄우지 않는다.**

## 공통 (모든 단계 · 최대 1회)

| 프롬프트 | 노출 조건 |
|---|---|
| **10번 중 몇 번은 이렇게 안 흘러가나요?** | 모든 단계. 0으로 답하면 → *"정말 한 번도요? 지난달에 이상했던 건 없었어요?"* 재질문 |
| 지난달에 이 일 하다가 **제일 오래 걸렸던 건**은 어떤 거였어요? | 흐름 완성 직후 1회 |
| 이 단계, **없애면 무슨 일이 생기나요?** | 승인/확인 성격 단계 (**ECRS 제거 후보 발굴**) |
| 이거 **당신 말고 할 수 있는 사람**이 있나요? | 담당자가 '나'로 3단계 이상 연속될 때 |

## 타입별

### 작업 `task`
| 프롬프트 | 트리거 |
|---|---|
| 이 단계에서 **다시 해야 했던 적**은요? 그러면 어디로 돌아가나요? | 항상 (→ `attrs.reworkRate`, `returnToItemId`) |
| 다음 사람한테 넘길 때 **뭘 같이 줘야** 하나요? | 다음 단계 담당자가 바뀔 때 (**핸드오프 소켓 생성**) |
| 이 앞 단계에서 **정보가 빠져 오는 일**이 얼마나 자주 있나요? | 담당자가 이전 단계와 다를 때 |
| 이거 **여러 건을 몰아서** 하세요, 아니면 건건이 하세요? | `freqLast7d ≥ 10` |
| 이 결과물, **어디에 저장**하세요? 나중에 누가 찾나요? | 산출물 명사 감지(보고서·대장·시트) |

### 분기 `branch`
| mode | 프롬프트 |
|---|---|
| 택1 | **어느 갈래가 제일 흔한가요? 10번 중 몇 번?** (분기 비중 없이는 리드타임 추정이 무의미) |
| 택1 | **아무 갈래에도 안 맞는 경우**는 어떻게 하세요? |
| 동시 | 이 중에 **하나만 늦어도 다음으로 못 넘어가나요?** (AND 병목 식별) |
| 동시 | 이 갈래들, **정말 동시에 하세요, 아니면 순서대로** 하세요? |
| 조건스킵 | **건너뛰는 조건을 누가 판단**하나요? 판단이 틀리면 어떻게 되나요? |
| 공통 | 판단 기준이 **문서에 있나요, 아니면 경험으로** 아시나요? (**암묵지 = 자동화 난이도 핵심 지표**) |

### 기다림 `hold`
| waitFor | 프롬프트 |
|---|---|
| 승인 | **반려되면 어디로 돌아가나요?** (필수) |
| 승인 | 최근 6개월에 **실제로 반려된 적** 있나요? → **없다**면 → *"그럼 이 승인은 왜 있나요?"* (**ECRS 제거 후보 자동 등록**) |
| 승인 | 결재자가 자리에 없으면(휴가·출장) 어떻게 하세요? |
| 승인 | 승인 기다리는 동안 **재촉을 몇 번** 하세요? 어떤 방법으로요? |
| 응답 | **답이 안 오면 며칠 기다리고, 그다음엔 뭘** 하세요? |
| 응답 | 상대가 **회사 밖 사람**인가요? (외부 대기는 리드타임 리스크 등급이 다름) |
| 응답 | 재촉할 때 **연락처를 어디서** 찾으세요? |
| 시각 | 그 시각을 **놓치면** 어떻게 되나요? 다음 기회는 언제인가요? |
| 시각 | 마감 직전에 **몰려서 처리**하게 되나요? |
| 자원 | 그게 **언제 오는지 어떻게 아세요?** 알림이 오나요, 직접 확인하세요? |
| 자원 | 기다리는 동안 **다른 일로 넘어갈 수 있나요**, 아니면 붙잡고 있어야 하나요? |

## 도구별

| 도구 | 예외 프롬프트 |
|---|---|
| 엑셀 | **파일 버전이 꼬이면 어떻게 하세요?** (`최종_최종_v3` 문제) |
| 엑셀 | 이 파일, **다른 사람도 열어야** 하나요? 동시에 열면요? |
| 엑셀 | 수식이 깨지거나 **틀린 값이 들어간 걸 나중에 발견**한 적 있나요? |
| 구글시트 | 권한 없는 사람이 요청하면 누가 열어주나요? |
| 한글(HWP) | 상대방이 **hwp를 못 열면** 어떻게 하세요? |
| 이메일 | 메일이 **스팸으로 갔거나 못 받았다는 연락**은 얼마나 자주 오나요? |
| 이메일 | **참조에 누구를 넣어야 하는지** 어떻게 아세요? 빠뜨린 적 있나요? |
| 슬랙 | 그 채널을 **아무도 안 봤을 때**는 어떻게 하세요? |
| 슬랙 | 여기서 결정된 걸 **다른 데에 다시 적어야** 하나요? |
| 카카오톡 | **회사 시스템에도 같은 내용을 다시** 적으세요? |
| 카카오톡 | 이 대화, **나중에 찾아봐야 할 일**이 생기나요? 어떻게 찾으세요? |
| 전화 | 통화 내용을 **어딘가에 기록**하세요? 안 하면 나중에 어떻게 되나요? |
| 전화 | 상대가 **전화를 안 받으면** 몇 번 더 걸고, 그다음엔요? |
| ERP | ERP에 넣기 전에 **다른 데(엑셀/메일)에 먼저** 적어두세요? |
| ERP | 잘못 입력한 걸 **수정하려면** 어떻게 하세요? 혼자 되나요? |
| 그룹웨어 결재 | 결재선을 **매번 직접 지정**하세요? 누구를 넣을지 어떻게 아세요? |
| 그룹웨어 결재 | 급할 때 **구두로 먼저 진행하고 결재는 나중에** 올리는 경우가 있나요? |
| 홈택스 / 4대보험 | **인증서 때문에 막힌 적** 있나요? 그럼 누가 해주나요? |
| 홈택스 | 발행 후 **잘못된 걸 발견하면** 어떻게 하세요? |
| 종이 / 인감 | **원본은 어디에 보관**하나요? 잃어버린 적 있나요? |
| 종이 / 인감 | 도장 찍을 사람이 **자리에 없으면** 어떻게 하세요? |
| 구두 요청 | 이걸 요청받았다는 걸 **어디에도 안 적어두면**, 잊어버린 적 있나요? |
| 택배사 | **분실·파손**이 나면 그때부터 뭘 하세요? |
| 판매 채널 | **채널마다 규칙이 다른** 부분이 있나요? |
| 채널톡 / CS 툴 | 같은 고객이 **다른 채널로도 문의**하면 어떻게 알아채세요? |
| CRM / 영업대장 | 이 정보를 **다른 곳에도 똑같이** 적어야 하나요? |
| 카드사 웹명세 | 카드사가 **여러 곳이면** 각각 하시나요? |

## 흐름 완성 직후 (전체 1회, 최대 2문항)

| 프롬프트 | 목적 |
|---|---|
| 이 일 전체에서 **제일 짜증나는 순간**이 언제예요? | 짜증 플래그를 놓친 단계 회수 |
| 만약 **누가 대신 이 일을 해야 한다면, 어디서 제일 헤맬 것** 같아요? | 암묵지 = 문서화 공백 = 자동화 난이도 |

| 이 일 **끝나고 나면 누구한테 넘어가나요?** | 핸드오프 소켓 (조직 조립 조인 키) |
